01 / The challenge

Problem Statement & Objectives

◎

Problem Statement

Investigating a suspicious domain or IP can require analysts to switch between different platforms. Gathering and comparing results separately takes time and complicates preliminary analysis.

OpenSignal brings relevant public intelligence into one interface.

Project objectives
  • Check domain and IP reputation.
  • Review reported open ports and exposed services.
  • Discover public certificate transparency records.
  • Present findings in a unified dashboard.
  • Support quick preliminary investigations.

03 / Core capabilities

Main Features & Modules

◉

Threat Reputation

Uses VirusTotal to retrieve available malicious, suspicious, harmless and undetected statistics.

⌁

IP Exposure Analysis

Uses Shodan to retrieve available host details, reported open ports and exposed services.

▣

Certificate Discovery

Uses crt.sh to find publicly available certificate records associated with a domain.

▦

Unified Dashboard

Organizes investigation results, provider status and recent searches; demo mode can show sample data.

Live results depend on provider availability, target coverage and valid API credentials where required.

Testing scenarios
  • Valid domain or IP: lookup begins.
  • Invalid input: validation error.
  • Missing API key: provider limitation shown.
  • Demo mode: sample results displayed.
  • API unavailable: failure handled gracefully.

05 / Wrap-up

Conclusion & Future Scope

✓

Conclusion

OpenSignal centralizes several public intelligence lookups in one interface, helping users perform preliminary domain and IP investigations more efficiently.

It supports investigation; it does not guarantee that a target is safe.

Future enhancements
  • User authentication and role-based access.
  • Secure database for investigation history.
  • PDF / CSV report export.
  • Scheduled monitoring and alerts.
  • More intelligence sources and visual analytics.
  • Secure production deployment.
